# PG Python Tanks

A 2D arcade tank game built using Python and Pygame. Aviable at [github.com](https://github.com/adamjohnwood/pg-python-tanks/blob/main/entities/enemy_tank.py)

## Prerequisites

- Python 3.x
- Pygame

## How to Run

1. Install the required dependencies:

   ```bash
   pip install pygame
   ```

2. Run the game:

   ```bash
   python main.py
   ```
